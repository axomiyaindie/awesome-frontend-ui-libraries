# awesome-frontend-ui-libraries

A curated list of frontend UI libraries that developers actually install and use to build web apps — with an eye toward avoiding generic, "AI-slop" interfaces.

## Why this list?

Most UI library lists are either stale or bloated. This one focuses on:
- **Real adoption** — libraries with active maintenance and meaningful usage.
- **Design control** — clear notes on which libraries give you freedom vs. which impose an opinionated look.
- **Anti-slop** — flagging libraries that make it easy to build distinctive, non-generic UIs (headless primitives, source-owned components) versus those prone to "default theme" sameness.

## Categories

### Full-Featured Design Systems
Powerful, batteries-included component libraries. Great for speed — but beware default themes that can look generic.
- [MUI](https://mui.com/) — React, Material Design.
- [Ant Design](https://ant.design/) — React, enterprise-focused.
- [Mantine](https://mantine.dev/) — React, highly customizable.
- [Chakra UI](https://chakra-ui.com/) — React, accessible primitives.
- [Vuetify](https://vuetifyjs.com/) — Vue, Material Design.
- [PrimeVue](https://primevue.org/) — Vue, rich component set.

### Headless / Unstyled Primitives
Maximum design freedom — anti-slop by nature. You bring the styles.
- [Radix UI](https://www.radix-ui.com/) — React primitives.
- [React Aria](https://react-spectrum.adobe.com/react-aria/) — React, accessibility-first.
- [Headless UI](https://headlessui.com/) — React & Vue.
- [Ark UI](https://ark-ui.com/) — Multi-framework headless components.
- [Bits UI](https://bits-ui.com/) — Svelte headless components.

### Copy-Paste / Source-Owned
You own the code, full customization, no dependency lock-in.
- [shadcn/ui](https://ui.shadcn.com/) — React.
- [shadcn-vue](https://www.shadcn-vue.com/) — Vue.
- [shadcn-svelte](https://www.shadcn-svelte.com/) — Svelte.

### Utility-First / Styling
- [Tailwind CSS](https://tailwindcss.com/) — utility-first CSS.
- [UnoCSS](https://unocss.dev/) — instant atomic CSS engine.
- [Panda CSS](https://panda-css.com/) — CSS-in-JS with build-time generation.

### Specialized / Motion & Data
- [Tremor](https://tremor.so/) — dashboards & charts.
- [Framer Motion](https://www.framer.com/motion/) — React animation.
- [Motion One](https://motion.dev/) — lightweight animation.

## Contributing

PRs welcome. Please ensure any library you add:
1. Is actively maintained (commits within the last 12 months).
2. Has meaningful real-world adoption.
3. Includes a one-line note on its design philosophy (opinionated vs. headless).
