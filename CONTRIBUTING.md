# Contributing

Thanks for wanting to add a library. Please follow these rules.

## Criteria for inclusion

A library must meet **all** of the following:

1. **Actively maintained** — at least one commit in the last 12 months.
2. **Real adoption** — meaningful usage in production apps (npm downloads, GitHub stars, or documented case studies). No abandoned experiments.
3. **Relevant** — it is a UI library, component library, design system, or styling tool for building web frontends.
4. **Documented** — has a working docs site and install instructions.

## What to include in your PR

- Add the library under the correct category in `README.md`.
- Format: `- [Name](https://link) — one-line note on framework + design philosophy (opinionated vs. headless).`
- If no category fits, propose a new one in the PR description.

## What will be rejected

- Abandoned or archived projects.
- Libraries with no documentation.
- Pure marketing pages with no installable package.
- Duplicates of an existing entry.

## Anti-slop note

This list favors libraries that give developers **design control**. Libraries with strongly opinionated default themes are welcome, but please note that in the one-liner (e.g., "opinionated Material Design theme").
